# Artwork and illustrated reading

Before generating, replacing, publishing, or integrating artwork, read
[`specs/artwork/ARTWORK.md`](specs/artwork/ARTWORK.md). It records the owner's
approved image-generation, responsive fitting, storage, and reader-setting rules.
Use this policy for future books and lessons, not only the current Īśopaniṣad set.

The illustrated reader's default image opacity is **48%**. Preserve a reader's
explicitly saved settings. All Sanskrit, transliteration, translations, teaching
tables, and controls remain real app content separate from the image.
