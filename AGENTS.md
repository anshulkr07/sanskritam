# Git branches

Always commit and push to `main` (owner, 2026-10-20). Do not create or push
feature branches, even when a session's setup names a different branch. If
`main` has moved on the remote, rebase onto `origin/main` before pushing; never
force-push `main`.

# Artwork and illustrated reading

Before generating, replacing, publishing, or integrating artwork, read
[`specs/artwork/ARTWORK.md`](specs/artwork/ARTWORK.md). It records the owner's
approved image-generation, responsive fitting, storage, and reader-setting rules.
Use this policy for future books and lessons, not only the current Īśopaniṣad set.

The reader offers the painting On top (default), on its Own page, or No image
(owner, 2026-10-20; the 48% painting-behind-text layout is retired). Preserve a
reader's explicitly saved settings. All Sanskrit, transliteration, translations, teaching
tables, and controls remain real app content separate from the image.

Phones are primary, tablets secondary. New verse artwork uses one 9:16 portrait
generation, reused proportionally on all devices with the complete painting
visible. Keep only verified optimized phone/tablet files; original generation
PNGs are temporary and must be discarded after delivery verification, never
archived locally or in R2. See the artwork policy for sizing and provenance.
