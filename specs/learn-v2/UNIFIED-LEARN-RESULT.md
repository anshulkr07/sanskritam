# Unified Learn implementation

Implemented locally on 12 October 2026 after the owner's “lets implement it then” instruction. The existing Path and Grammar bottom tabs are consolidated into **Learn**. Bottom navigation is now **Home / Learn / Talk / Play / Read**.

## What is working in source

- **Course:** an 18-chapter map. Chapter pages connect the existing assessed lessons, verified card lessons and reference readings for that subject. The original eleven-unit course remains reachable through “Continue your course”.
- **Reference:** all 18 chapters / 105 topics, read counts and the existing reading bookmark. The complete reference browser, levels, quizzes, related topics, glossary and offline cache remain reachable.
- **Practice:** assessed course practice, challenges, vocabulary, Word Lab, sounds, writing, word order, noun/verb paradigms and rhythm.
- Search spans assessed lesson titles/features, reference titles/summaries/chapter IDs and card lesson titles/IDs/outcomes in English, Hindi, Devanagari and IAST. Searching “sandhi” finds all six available Sandhi card lessons.
- All **49 existing assessed lessons are assigned once** to a home chapter. All **105 reference topic IDs** and **seven verified card lessons / 62 cards** are retained. Unknown future server lessons remain discoverable in search and in the complete course.
- Existing unit unlock conditions and card prerequisites are preserved. Opening a chapter or reading a topic does not transfer or award mastery.
- Old `Path` and `Grammar` route names now resolve to stack screens. Story links are updated for these routes and for the drawer/tab nesting. Lesson, GrammarChapter, GrammarTopic, LearnV2Lesson, assessment and tool routes are preserved.

## Progress and content

No progress migration was needed. The unified entry reads the existing server course data, Grammar read marks/bookmark and Learn V2 card progress. It introduces no new mastery writes, resets, identifiers or production data changes. A chapter's count is a count of available activities, not a new mastery score.

The unified catalogue exposes existing content; it does **not** mean 156–187 new card decks or 200–300 new illustrations have been completed. New-format content still consists of seven lessons / 62 cards; the seven remaining Sandhi lessons and 48-lesson Verse manuscript need adaptation/verification. The image queue still has three ready and two draft requests; three generated PNGs remain distinct from the three integrated prototype JPGs. Full-course authoring and image generation remain outstanding in the [whole-course audit](WHOLE-COURSE-AUDIT.md).

## Checks and preview

The production screens have a static React Native Web visual fixture, regenerated by `node scripts/render-unified-learn.cjs` into `specs/learn-v2/unified-learn-qa.html`. That page is not versioned: it embeds every artwork as a data URI so it renders standalone, which makes it about 16 MB, and each regeneration would add that to git history. The durable evidence is committed instead, as the [full screenshot](unified-learn-qa.png) and [summary screenshot](unified-learn-summary.png). It covers Course at 320px, Reference at 390px, Practice at 320px, Cases in Hindi at XL text scale (1.6), global search and failed-fetch states. All six fixture containers have no horizontal overflow. All 58 artwork placements load. Hooks use read-only curriculum/language/type-size fixtures; this proves layout, not native gestures, live API integration, interactive tab switching or real-user progress persistence.
