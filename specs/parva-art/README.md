# Parva artwork: festivals and the nine forms

Style: the Read covers and Path cards watercolour and gouache (specs/path-art/README.md).
Warm, calm, devotional, natural anatomy, no text in the image, no frame, no
watermark, faces dignified. Never sexualised, never gory (Kalaratri is fierce
but drawn with reverence; follow the verse, not a horror look).

Export: WebP, 1200 px wide hero, quality 86 (backend/scripts/parva_art_import.py).
The owner runs the image model (generated, owner decision 2) from the prompts
below, checks each painting against its checklist, then imports and approves.
A deity with no sourced verse gets no painting (9.2): checklists below marked
"source pending" are placeholders for the owner to replace with the dhyana
verse before approving. No painting is served before approved.

## Phase 1

Checklist (source pending, no verse sourced in this work): four arms; upper
